# Contributing

Thanks for taking an interest. Please read this before opening anything. It's short.

## TL;DR

- **herdr-command-palette** is open source, not open contribution. The code is public so you can read it, use it,
  fork it and learn from it. I'm not looking for contributors right now.
- Unsolicited pull requests will be closed without review. This isn't personal; it's how I keep the project maintainable.
- Bug reports, questions and well-reasoned ideas are welcome.
- Want to change code? Start a conversation first. If we agree on the change, I'll invite a PR.

## Why it works this way

This project is maintained by one person in their spare time. Reviewing a pull request, even a small one, takes real
time: understanding the intent, checking edge cases, thinking about long-term maintenance, and then owning that code
forever.

Writing code has become cheap. Reviewing it hasn't. Keeping contributions behind a conversation lets me spend my
time on the project rather than on triage.

Forking is always welcome. That's what the license is for.
